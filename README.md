# Risk Management System

A full-stack Risk Management Application built using React and Spring Boot.

---

## Features

- Add, Edit, Delete Risks
- AI Risk Analysis
- CSV Export & Upload
- Analytics Dashboard
- Pie Chart & Bar Chart
- Risk Detail Page
- Demo Data Seeder
- Performance Optimization

---

## Tech Stack

Frontend:
- React.js
- Axios
- Recharts

Backend:
- Spring Boot
- Java
- REST API

Database:
- MySQL / H2 Database

Tools:
- Git & GitHub
- Postman

---

## Project Architecture

React Frontend
↓
Spring Boot Backend
↓
Database

---



## API Endpoints

GET /api/risks

POST /api/risks

PUT /api/risks/{id}

DELETE /api/risks/{id}

GET /export

POST /upload

---

## How To Run

### Backend

1. Open backend folder
2. Run Application.java

### Frontend

1. Open frontend folder

2. Install dependencies

npm install

3. Run frontend

npm run dev
