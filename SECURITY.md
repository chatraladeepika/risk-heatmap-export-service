# Security Policy

## Supported Versions

The following versions of the Risk Management App are currently supported with security updates.

| Version | Supported |
| ------- | ---------- |
| 1.0.0   | ✅ Yes |

---

## Reporting a Vulnerability

If you discover any security vulnerability in this project, please report it responsibly.

### How to Report

- Create a private issue if available
- Contact the project maintainer directly
- Include detailed steps to reproduce the issue
- Provide screenshots or logs if necessary

---

## Security Measures Implemented

This project includes several security-focused practices:

- Input validation for risk data
- Protected API endpoints
- Error handling and validation
- Safe frontend-backend communication
- Dockerized deployment support
- Environment variable configuration using `.env`
- Secure REST API architecture

---

## Best Practices Followed

- Separation of frontend and backend services
- Modular code structure
- Secure API request handling
- Controlled state management
- CSV export handling with validation

---

## Future Security Improvements

Planned enhancements include:

- JWT Authentication
- Role-Based Access Control (RBAC)
- HTTPS deployment
- Rate limiting
- Audit logging
- Advanced vulnerability scanning

---

## Responsible Disclosure

Please avoid publicly disclosing vulnerabilities until they have been reviewed and resolved responsibly.

Thank you for helping improve the security of this project.
